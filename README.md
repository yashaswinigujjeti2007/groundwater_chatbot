# Groundwater Chatbot 🌊

## Overview

Groundwater Chatbot is a web-based chatbot project designed to provide information and assistance related to groundwater.

The project includes a frontend interface and a backend server for handling chatbot interactions and storing chat history.

## Features

- 💬 Interactive chatbot interface
- 🌊 Groundwater-related information
- 📜 Chat history
- 💾 SQLite database for data persistence
- 🌐 Web-based user interface
- ⚙️ Node.js backend

## Technologies Used

- JavaScript
- HTML
- CSS
- Node.js
- SQLite
- Express.js
